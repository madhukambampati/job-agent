# Evidence notes

Put markdown files here describing work you have really done: project READMEs,
notes about your day job, talks, write-ups. Each bullet or paragraph becomes a
piece of evidence the agent can retrieve when a job asks for something.

The editor can only lean on evidence that exists, so this is how to give it more
to work with honestly. This README itself is skipped only because it says
nothing about you; real notes are picked up automatically.
