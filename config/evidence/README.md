# Evidence notes

Put markdown files here describing work you have really done: project
write-ups, notes about your day job, talks. Each bullet or paragraph becomes
evidence the agent can retrieve when a posting asks for something.

The editor can only lean on evidence that exists, so this is the honest way to
give it more to work with. This README is ignored; every other .md file here is
indexed (and gitignored, so your notes stay on your machine).
